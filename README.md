# 5035 流動性獵取掃描器（Liquidity Hunter）

掃描加密貨幣（之後擴充美股）歷史 K 線，找出「**流動性獵取 / Stop Hunt**」型態。
方法論依「貝格先生 @market_beggar」的推文整理，詳見 [METHODOLOGY.md](METHODOLOGY.md)。

## 偵測什麼
**獵取目標（流動性聚集區）**：等高 / 等低（**觸碰數 = 價格進出該價帶的次數**，**≥2 次** 起；2=EQH/EQL、3+=強共識）＋ 足夠顯著的前高 / 前低
報告可用「**最少觸碰**」滑桿動態拉高門檻（≥2/≥3/≥4），並有「**對數座標**」切換（大範圍標的如 MU 必備）
**獵取型態（兩側都做）**：
- **A 影線插破收回**：影線插破聚集區極值、收盤收回內側（看空 A高 / 看多 A低）
- **B 假突破收復(MSB)**：收盤假突破後停留數根又站回（看空 B高 / 看多 B低）

**有效 S/R 規則**：觸碰須是「獨立、被尊重的擺盪」（離開價帶 `sep_pct` 才算下一次觸碰，連續 K 棒只算一次）；且**突破須距「最後一次建立觸碰」至少 `min_hold` 根（站穩期）**——不能第 2 次碰到就突破，否則不算有效支撐/阻力。
**插破深度不設限**：獵取插多深都算（深插掃止損反而是最強獵取），`max_pierce` 僅作極端 sanity 界線；真正判準是下面的「收復+反轉」。
**確認時點**：訊號在 pattern 完成那根成立——A=插破收回當根、B=收盤收復當根（真崩盤不會收復，自然被濾掉）；且 B 型插破極值須超出 `touch_tol` 容忍帶（沒掃到止損帶的微量假突破不算）。刻意不用「之後 N 根走勢」過濾（前視偏誤，即時監控做不到）。
**B 型真突破防護（視覺 QA 修訂）**：acceptance 積分（每根收盤超出線的距離/ATR 累加）> 4.0 即作廢——插越深容許停留越短，「深插秒回=獵取、深插久留=真突破住下來」；收復收盤須站回線內側 ≥0.15×ATR（貼線的猶豫收復不算）。校準依據：9 個人工標注的 1d 案例實測積分（好案例 ≤3.6、假陽性 ≥4.5）。
**進場分流（交易層，非 detector）**：detector 純偵測、輸出所有候選訊號；「弱收復的訊號要不要進場」交給交易層（回測 backtest／監控 market_scan）依**收復站回流動線的力道**決定——詳見下方回測段與監控段的「進場分流」。（曾誤試 detector 層「隔根破針尖就撤銷」`confirm_bars`，但進場在次根開盤、判定卻用次根收盤＝未來洩漏，已撤回改用此法；）
**線的明顯性（方法論前提，使用者裁決門檻）**：線誕生前 20 根被切過 **2 次即不行**（`max_birth_tan=1`）——線生在舊密集區就不「明顯」，散戶止損不會一致堆在它後面，不符獵取前提。髒帶被擋後，同價位若有乾淨出生的新帶會自然承接（ACGL 實例）。取捨依人工標注案例實測決定。
**大級別假跌破收復（macro spring，1d 啟用）**：補抓「非 3~5 根 V 轉」的大週期獵取——強等高低帶（`touches≥spring_min_touches`=4）收盤跌破後磨數週、深掃、再強勢收盤站回原線（Wyckoff Spring）。新增獨立狀態 `SPRING_WAIT`：`DEVIATED 超時/acc 爆表且通過 spring 資格 → SPRING_WAIT 潛伏 →（收盤站回原線 + 深掃 + 住夠久）→ emit B → DEAD`。三道結構閘防爆量：①強帶 `touches≥4`（真堆疊止損、非單一 prominent 前高）②深掃 `spring_min_depth`≥10%（針尖須比原線深破，淺破雜訊擋外）③時長 `spring_min_bars`≥7 根（> `max_below`=6，磨夠久才算大級別）；收復一發生即結算（達標 emit、否則靜默死），不延遲。卡點 A：強帶僅因 `min_hold` 未過被收破時保留 NORMAL 等站穩（影線/收盤兩版鏡像）。QTUM 2020 案例（touches=5、深掃 −18%、住 3 週、收復）固化於 `regression_qa.py`。全市場 spring 訊號占基準 1.4%。
**線復活（多級獵取，1d 啟用）**：修「一條線 emit 一次就 DEAD」缺陷——對齊作者「同一流動性區會被更深地獵取多次（一級一筆單）」。第一級收復 emit 後線進 ZOMBIE 潛伏，被「**更深新針尖**（≥`rearm_gap`=0.5ATR）」再獵取時收復舊線 → emit **第二級(`rearm_level=2`)**。五道結構閘防刷：更深針尖／站回舊線／**第二級硬性 taker**／封頂 2 級／TP觸及·換戰場·逾時(`zombie_ttl`=20)→永久死。全程只用當下及更早 K 棒（無前視）。第二級 taker 放寬為「插破→收復**整段窗口**」判定（`m1_window_confirm`，CRV 型漸進吸籌的分散買盤過得了；L1 維持嚴格節點）。

## taker/CVD 確認（crypto=1 分 K 精準判定 taker_1m.py；美股=日線放量 taker.py）
**crypto ⚡ 由 1 分 K 判定（作者實際做法：觸碰流動性後看小級別 taker）**：
兩個精準節點任一成立即 ⚡——「**極值**」=極值根 ±2 根內（作者第 1 種進場：當下反向強力 taker）、
「**收復**」=首次 1m 收盤站回線 +2 根內（作者：監測漲回/跌回區間時的強力 taker），
存在同時滿足 量>當日PR99、主動方佔比>0.6、名目額>max(當日0.1%, 5萬U) 的 1m。
⚠ 美股 ⚡ 是「放量」近似（無方向性，無法排除真突破的爆量）——與 crypto 1m ⚡ 證據強度不同級，解讀須打折。
採用依據＝**方法論定義**（作者實際做法），非回測績效：點估 1m⚡ 做多 PF 2.72 vs ✗ 1.68，
但 fable 審查判定**增量尚無法統計證明**（n=38、CI 跨零、去 2 筆尾部即反轉、樣本外僅 3 筆），
留待樣本累積驗證。日線 z 降為輔助顯示。每命中多 1~2 個 API 請求（磁碟快取）。
以下為日線層（美股放量判定 + 輔助 z）：
作者的真假獵取判別法「強力 taker 介入即是確認」已量化：delta 的 60 根滾動 z-score，
**吸收**（插破段獵取方向爆量被接走）與**反轉**（反方向爆量）兩成分取大。
門檻用 **Šidák 校正**：B 型窗口取 max 等於多看幾次，固定門檻會讓長窗口白拿 ⚡，
故按比較次數校正——A型(單根)≈1.54、B型6根窗≈2.33（ALPHA=0.12，純雜訊通過率實測 10.3%）。
軟標記不硬砍：訊號照列、推播加 ⚡ 字樣，report/scanner 都有「僅⚡確認」開關，回測可掃 ALPHA。
實證 BTC/ETH/SOL 1d 共 39 訊號確認 16（41%；B 型 38% vs 雜訊地板 10%），
2024-08-05、2025-02-03 等經典插針全數 ⚡。
**美股無 taker 拆分 → 用「放量」近似**：log(成交量) 的 60 根滾動 z（log 後近常態），
同窗口、同 Šidák 校正、單成分（kind=放量）——獵取要嘛沒人理、要嘛放量，至少濾掉無量假收復。

## 全市場掃描 + 每日監控（market_scan.py）
掃 Binance USDT 永續(預設**全 527 檔**；`--min-qvol 5e6` 可設流動性門檻只掃 207 檔) + 美股 S&P500+NASDAQ100，列出三類 **B 型獵取**到前端 `scanner.html`：**(1)👁觀察中（弱收復、進場分流尚未確認進場）**、**(2)🟢持倉中（已進場、v5 未出場）**、**(3)近 days 天已依 v5 出場（停利 tp／移停 trail／停損 sl）**，附 taker 確認標記（⚡）與篩選鈕。
  ⚠ 全掃含低流動性小幣：taker z-score 較易失真、殭屍幣假等低較多（已由 birth_tan 明顯性過濾 + 名目額底線部分擋下）；要乾淨池子用 `--min-qvol 5e6`。
- **觀察視圖**：弱收復、進場分流尚未確認進場的訊號標「觀察中」（站回達門檻→轉持倉；跌破針尖→下次掃描消失）
- **持倉視圖**：持倉中的單只要依 v5 框架尚未出場就持續顯示、不受時間窗限制（多日前收復、還在持倉的照樣留著）；已出場的單只顯示近 days 天內出場者（避免歷史停損單全冒出來）。進場分流＋`_v5_open` 與 backtest 逐筆同構（2229 筆交叉驗證 0 不一致）
- **狀態篩選鈕**：全狀態 / 👁觀察 / 🟢持倉 / ✅停利 / 🔴停損·移停（與市場、多空、⚡ 鈕可疊加）
- 每列標：狀態標籤、持倉天數（或「持 N 日→出場日」）、近 days 天剛收復=「新」標記、結構移停狀態；圖上畫**停損線（持倉中=當前結構移停水位）+ TP 線 + 出場點標記**（✓止盈／移停／✕停損）

### 出場框架（v5 結構移停＝localhigh，TP/SL 取捨見 METHODOLOGY.md）
作者親口：**SL=Stop Hunt 後的針尖高/低點**、**TP=下一個 Liquidity 聚集區**。本工具：
- **初始 SL**=插破極值＝跌破/突破流動線後的最低/最高點（作者「針尖高/低點」，非收復根低點）✓ 與作者一致
- **TP 目標**（`opp_level`）=下一個流動性聚集區＝**對側最近的活躍價帶**（B低=上方最低高帶／B高=下方最高低帶）。
  **不要求 touches≥2/prominent**——任何前高/前低都是流動性（下跌趨勢的 lower-high 也算 TP）；用「活躍帶」
  自動濾掉過期/遠古無關價位。曾過度收緊成「touches≥2 或 prominent」，導致下跌趨勢 B低（如 VIC）找不到 TP
  →被當無目標/假停損，已放寬（VIC 從假 sl 變 +7.3ATR tp；到聚集區率 23%→35%、PF 1.18→1.21）。
- **途中 localhigh 移停（使用者準則）**：沿走勢高低點結構移停——**每出現一個更高的 swing low(多)/更低的
  swing high(空)→SL 上移到「前一個 swing low/high」**（兩個 low 之間最高點＝local high；沒 lower low 就一路跟）。
  比舊 retest 法（只在回踩收復線附近移停）更能讓趨勢單奔跑：CRV 2022 那筆 −2.58→**+4.8 ATR**。
- 出場三類：tp(漲到聚集區) / trail(結構移停 SL 上移再被掃) / sl(初始停損)
- 回測(全掃·localhigh+新opp)：做多 PF **1.21**、勝率 **38.3%**、到聚集區 **35%**、平均 +0.248 ATR（n1337）；
  做空照樣負(0.86，與移停/TP 無關)（`--trail retest` 可切回舊移停做對照）
- 前端自繪 K 線（不連 TradingView）：支撐/壓力線 + 觸碰點 + 獵取標記 + 停損/停利目標線；**開高低收** legend；**📏 量尺測量**
- `python market_scan.py --days 7`          # 手動全掃（days 決定「近期出場標的」顯示窗 + 「新命中」標記窗；持倉中不受限）
- `python market_scan.py --days 7 --notify` # 全掃 + 推播「近 days 天新收復」命中（持倉中舊單不重複推；推播走 LH_NOTIFY_SCRIPT 環境變數指定的腳本）
- 狀態檔 `scan_state.json` 記錄已通知過的命中（近 30 天 key）
- Binance 已加節流(0.3s)+429/418 退避，避免 IP 被 ban

## 回測結論（backtest.py，完整報告見 BACKTEST.md；數字=偵測器視覺QA修訂後）
全市場日線、ATR 標準化、次根開盤進場、扣費用、冷卻期防自相關、3610 筆訊號：
- **優勢在「做多(B低) + 20 根持有」**：勝率 54.6%、PF 1.57（修訂前 1.53）；
  ⚡ 組 56.9%/PF 1.80、⚡+touches≥3 60.0%/PF 2.06，樣本外(≤2022)⚡ PF 1.85
- **幾何修訂吸收了部分 ⚡ 的工作**：acceptance 積分把「真突破假陽性」先殺掉後，
  非⚡組品質上升（PF 1.42→1.48），⚡ 邊際增益從 +7.2%(顯著) 縮到 +3.4%(不顯著)——
  ⚡ 仍為正貢獻且為原文要求的必要確認，推播只列 ⚡ 明細
- 短週期(3~10根)無優勢；**做空(B高)全面虧損**（PF 0.70），僅供參考、不當進場依據
- 倖存者偏差使絕對績效偏樂觀；⚡ vs 非⚡ 為同樣本相對比較，較穩
